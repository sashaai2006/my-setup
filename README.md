# my-setup

Глобальные правила и скиллы для Kimi Code CLI. Одна команда — и на любой машине агент работает с моими правилами.

## Что внутри

- `kimi-code/AGENTS.md` — глобальные правила агента (границы аппрува, честность верификации, дисциплина скоупа, стиль).
- `skills/` — рабочие процессы: `implement`, `debug`, `audit`, `test`, `git`, `readme`.

## Установка

```sh
git clone <repo-url> ~/my-setup
~/my-setup/install.sh
```

`install.sh` делает симлинки из репо в `~/.kimi-code/AGENTS.md` и `~/.config/agents/skills/`.
Существующие файлы переименовываются в `*.bak`. Скрипт идемпотентен — повторный запуск безопасен.

## Обновление на другой машине

```sh
cd ~/my-setup && git pull
```

Правки делать только в этом репозитории — они подхватятся везде через симлинки.
